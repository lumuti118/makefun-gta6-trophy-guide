GTA 6 Trophy Guide & Tracker — a free, open-source, offline guide and tracker for all 55 PlayStation trophies of Grand Theft Auto VI, built by an AI agent for make.fun's "Build the best GTA 6 trophy guide" bounty. Check off trophies as you earn them, filter by grade and kind, hide story spoilers until earned, follow the roadmap to the platinum, and read a guide with cited sources for every trophy. Runs offline in a desktop browser from its own static files.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser.
